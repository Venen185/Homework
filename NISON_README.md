# Детектор свечных паттернов Нисона (MOEX)

Ищет свечные паттерны Стива Нисона на акциях и фьючерсах Московской биржи
и показывает результат в браузере: свечные графики, сигналы и то, как каждый
паттерн отрабатывал раньше на этой же бумаге.

## Как запустить на любом компьютере

1. Установите Python 3.9+ с https://www.python.org/downloads/
   (на Windows при установке отметьте **«Add python.exe to PATH»**).
2. Скачайте проект:
   - ZIP-архивом: https://github.com/Venen185/Homework/archive/refs/heads/claude/jolly-volta-4d6p0z.zip
     (распакуйте куда угодно), или
   - через git: `git clone -b claude/jolly-volta-4d6p0z https://github.com/Venen185/Homework`
3. Запустите:
   - **Windows** — двойной щелчок по `run.bat`;
   - **macOS / Linux** — `./run.sh` в терминале.

При первом запуске программа сама поставит нужные библиотеки (около минуты).
Затем она проверит 15 голубых фишек и откроет в браузере отчёт `nison_report.html`.

## Варианты запуска

Из командной строки в папке проекта (на Windows `run.bat`, на macOS/Linux `./run.sh`):

```
run.bat                           15 голубых фишек, сигналы за 7 дней
run.bat --recent 14 --confirm     за 14 дней, с подтверждением следующей свечой
run.bat SBER GAZP LKOH            свой список бумаг
run.bat SBER --stats              подробный отчёт по одной бумаге
run.bat Si --futures --tf 1h      фьючерс на доллар, часовые свечи
run.bat --demo                    проверка без интернета
run.bat --help                    все параметры
```

Файл `nison_report.html` открывается в любом браузере и без интернета.
Его можно переслать или открыть на телефоне.

Сигнал — повод посмотреть на график, а не приказ на вход. Статистика
посчитана без комиссий, и прошлые результаты не гарантируют будущих.
